## Escopo

### Inclui
- `src/Integracoes/ParceiroFreteClient.php` (novo): `enviar(int $pedidoId, array $itens): RespostaParceiro` — POST `https://parceiro.example/envios` com `{pedido_id, itens[]}`; resposta de sucesso `{status: "ok", prazo_dias, itens: [{sku, desconto_pct}]}`.
- `src/Integracoes/RespostaParceiro.php` (novo): `sucesso(): bool`, `percentual(): Percentual|null` (o maior `desconto_pct` entre os itens), `motivo(): ?string`.
- `src/Pedidos/ConfirmacaoService.php`: após gravar `confirmado`, chama o cliente; sucesso → `PedidoRepository::gravarEnvio(id, percentual, 'enviado')`; falha/timeout → `gravarEnvio(id, null, 'pendente')` + `HistoricoRepository::registrar(id, 'envio_falhou', motivo)`.
- `src/Pedidos/PedidoRepository.php`: `gravarEnvio(int $id, ?Percentual $pct, string $envioStatus): void`.
- `tests/Integracoes/ParceiroFreteClientTest.php` (`@group integration`), `tests/Pedidos/ConfirmacaoServiceTest.php`.

### Não inclui
- Guarda do comprovante (TASK-001-003).
- Tela de detalhe e reenvio manual (TASK-001-004).
